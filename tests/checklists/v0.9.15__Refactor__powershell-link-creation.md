# Human Test Checklist: PowerShell directory-link creation (`create_link`)

**Target version:** v0.9.15 (dazzlecmd) / 0.8.17 (dazzlecmd-lib)
**Ships with commit:** `b50920e` v0.9.15 fix(lib,tests): #37 Tier-1 closeout -- PowerShell links + aggregator-name audit (refs #37)
**Companion automated tests:** `packages/dazzlecmd-lib/tests/test_core_links.py` (3: round-trip, spaced-path quoting, occupied-target refusal); the `dz mode switch` real-junction round-trip in `tests/test_mode_origins.py`.

## What this is

`core.links.create_link` is the **constitutional primitive** behind every `dz mode switch` into dev mode and `dz links`. On Windows it now creates directory links via **PowerShell `New-Item`** (`-ItemType SymbolicLink`, falling back to `-ItemType Junction`) instead of `cmd /c mklink`, which fails silently when invoked as a subprocess from bash/WSL (CLAUDE.md rule #4; #37 Tier-1 criterion). This checklist covers what CI can't: the **junction-fallback path on a machine WITHOUT Developer Mode / admin** (CI here ran with Developer Mode ON, so it only exercised the symlink path), real PowerShell-availability, path quoting on real paths, and real-terminal error output.

**SAFETY — read before running:** every step here operates in a **throwaway temp sandbox**. Do NOT run any `dz mode switch`/`restore` against a real tool, kit, or submodule. Do NOT edit your real `mode_local.json` or `~/.dz/config.json`. Deletions use `dz safedel` (recoverable). Nothing here should touch `C:\code\dazzlecmd\github\projects\`, `kits\`, or your installed tools.

## Prerequisites

1. Windows with PowerShell available on PATH (`powershell` — Windows PowerShell 5.1 is fine).
2. Know your **Developer Mode** state (Settings → For developers → Developer Mode). It decides which path `create_link` takes:
   - **Developer Mode ON (or elevated):** `New-Item -ItemType SymbolicLink` succeeds → `create_link` returns `"symlink"`.
   - **Developer Mode OFF (non-elevated):** SymbolicLink fails → falls back to `New-Item -ItemType Junction` → returns `"junction"`.
   - **The junction fallback is the path CI did NOT exercise here.** If you can test on a non-Dev-Mode box (or temporarily toggle it off), HV.2 is the highest-value check.
3. A scratch temp dir you can delete, e.g. PowerShell: `$SBX = "$env:TEMP\dzlink_sbx"; New-Item -ItemType Directory -Force $SBX`.

## High-Value Verification (~5 minutes)

### HV.1 — Basic link round-trip works (whichever mode your box yields)

- [ ] **Steps** (PowerShell):
  ```powershell
  python -c "import tempfile,os; from dazzlecmd_lib.core.links import create_link,remove_link,is_linked_project; t=os.environ['TEMP']+'\\dzlink_hv1'; os.makedirs(t+'\\src',exist_ok=True); open(t+'\\src\\f.txt','w').write('x'); m=create_link(t+'\\src',t+'\\link'); print('mode=',m); print('linked=',is_linked_project(t+'\\link')); print('reachable=',os.path.isfile(t+'\\link\\f.txt')); remove_link(t+'\\link'); print('src_intact=',os.path.isfile(t+'\\src\\f.txt'))"
  ```
- [ ] **Expected:** `mode= symlink` OR `mode= junction` (never `None`); `linked= True`; `reachable= True`; `src_intact= True`.
- [ ] **Why this matters:** the core primitive must produce a working link and remove it without harming the source.

### HV.2 — Junction fallback on a NON-elevated / Developer-Mode-OFF box (the CI gap)

- [ ] **Steps:** run HV.1 from a **non-admin** PowerShell with Developer Mode OFF.
- [ ] **Expected:** `mode= junction` (the SymbolicLink attempt failed and it fell back cleanly); `linked= True`; `reachable= True`. No stderr noise unless BOTH mechanisms fail.
- [ ] **Why this matters:** this is the path CI here never ran (this box has Dev Mode on). If the PowerShell quoting or fallback is wrong, mode-switch silently breaks for the majority of users who don't have Dev Mode.

### HV.3 — Spaced / special-char paths

- [ ] **Steps** (PowerShell):
  ```powershell
  python -c "import tempfile,os; from dazzlecmd_lib.core.links import create_link,remove_link,is_linked_project; b=os.environ['TEMP']+'\\dz link hv3'; os.makedirs(b+'\\a source',exist_ok=True); open(b+'\\a source\\k.txt','w').write('x'); m=create_link(b+'\\a source',b+'\\the link'); print('mode=',m,'linked=',is_linked_project(b+'\\the link'),'reachable=',os.path.isfile(b+'\\the link\\k.txt')); remove_link(b+'\\the link')"
  ```
- [ ] **Expected:** a real link mode, `linked= True`, `reachable= True`. (Regression for the `New-Item` single-quote path escaping.)
- [ ] **Why this matters:** a quoting bug would create the wrong link or none, silently.

### HV.4 — Occupied target is refused (no clobber)

- [ ] **Steps** (PowerShell):
  ```powershell
  python -c "import os; from dazzlecmd_lib.core.links import create_link; b=os.environ['TEMP']+'\\dzlink_hv4'; os.makedirs(b+'\\src',exist_ok=True); open(b+'\\occupied','w').write('keep me'); print('result=',create_link(b+'\\src',b+'\\occupied')); print('still=',open(b+'\\occupied').read())"
  ```
- [ ] **Expected:** `result= None`; `still= keep me` (the existing file is untouched).
- [ ] **Why this matters:** mode switch relies on create_link not overwriting an occupied path.

### HV.5 — End-to-end `dz mode switch`/`restore` on a SANDBOX tool (real junction)

- [ ] **Steps:** run the automated round-trip that creates a real junction + restores from an isolated trash store:
  ```
  python -m pytest tests/test_mode_origins.py::test_embedded_dev_then_restore_round_trip -q
  ```
- [ ] **Expected:** 1 passed. (This is the integration proof that create_link works inside a real mode swap. It uses a temp sandbox + isolated trash store — touches nothing real.)
- [ ] **Why this matters:** confirms the primitive works through the actual `_switch_to_dev` path, not just in isolation.

## What the automated tests DON'T cover

- **The junction-fallback path on a non-Dev-Mode / non-admin box** (CI here ran with Dev Mode on → symlink path only). HV.2 is the gap.
- A machine where `powershell` is absent from PATH (e.g., a stripped image) — `create_link` should return `None` cleanly, not raise.
- Real-terminal rendering of the failure message when BOTH SymbolicLink and Junction fail.
- Cross-volume link attempts.
