## HV.5 Regression Suite Details

- **933 passed, 5 failed, 6 skipped** (excluding `projects/` dir which contains wtf test collection errors)
- **5 failures are NOT regressions** -- they are an env-isolation artifact:
  - `test_config_dir_argument_routes_config_path`
  - `test_two_engines_have_isolated_configs`
  - `test_engine_with_config_dir_sets_override_root`
  - `test_engine_override_file_loaded_from_config_dir`
  - `test_two_engines_have_isolated_override_paths`
- Root cause: these tests create engines with explicit `config_dir=` but do NOT clear `DAZZLECMD_CONFIG` env var first. Since `DAZZLECMD_CONFIG` takes precedence over `config_dir`, the test assertions fail when `DAZZLECMD_CONFIG=/tmp/dz-tester-25.json` is set. The tests PASS when run without the env var. This is a test isolation gap in those tests (they should `monkeypatch.delenv("DAZZLECMD_CONFIG", raising=False)`), NOT a bug in the engine.
- Core `test_fqcn_index_alias.py` suite: **37/37 PASS**
