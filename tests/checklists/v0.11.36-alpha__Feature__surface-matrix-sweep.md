# Human Test Checklist: the derived SURFACE MATRIX sweep (anti-whack-a-mole)

**Target:** app `0.11.36-alpha` (`0bab77d`) on dazzlecmd-lib `0.10.20-alpha` (`b0aa0db`), dazzle-lib `0.8.2`.
**The engine:** `tests/one-offs/surface_matrix_gen.py` — walks the REAL derived tree and emits every probe (node-class × surface), currently **79 probes + 4 consistency rows**. Because probes are DERIVED, a new mount/rung/verb expands this checklist automatically — coverage grows with the structure, not with memory.

## How to run
1. Isolate: point `DAZZLECMD_CONFIG` at a throwaway path (cmd: `set DAZZLECMD_CONFIG=%TEMP%\mx\c.json` · PS: `$env:DAZZLECMD_CONFIG="$env:TEMP\mx\c.json"` · POSIX: `export DAZZLECMD_CONFIG=/tmp/mx/c.json`).
2. `python tests/one-offs/surface_matrix_gen.py --json` → execute EVERY `cmd` as a live `dz` invocation. PASS = exit 0 with a coherent card/listing (vacant-class probes must be nonzero-exit not-found); record any traceback, empty output, wrong-plane routing, or output that contradicts the node's class.
3. The 4 CONSISTENCY ROWS (rule-6): for every node with children, the info card's `contains` set == the listing's structure set; current/default markers agree card↔listing; every verb card's help line == the argparse help; the level axis agrees across {card, listing, bare read, `dz level`} in all 4 states {unset, set, post-delete, post-meta-reset}.
4. Verdict: SHIP/HOLD; per-class PASS counts; findings with exact output; repros to `tests/one-offs/`.

## What this replaces
Spot checklists for the info/listing surfaces. The matrix is the enumeration; hand-authored sections remain only for shell-rendering/quoting concerns (cold cmd.exe / `/V:ON` runs of a sample per class).
