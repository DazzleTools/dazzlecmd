# Human Test Checklist: v0.7.32 — Tier 1B — Library `render_info` parity (info-parity port)

**Target version:** v0.7.32 **Ships with commit:** TBD (info-parity port; prerequisite for v0.7.33 X-22-narrow) **Companion automated tests:** 975 passing in `tests/` (8 new tests in `tests/test_default_meta_commands.py::TestRenderInfo`)

## What this is

v0.7.32 ports the missing `info` display behavior from dazzlecmd's `_cmd_info` to library `dazzlecmd-lib::render_info`. After this commit, library consumers (amdead, wtf-windows, sysdiagnose, future personal aggregators) get the full info surface for free — `--raw` and `--platform` flags, conditional-dispatch runtime resolution, qualified-alias provenance, pass-through marker, Python deps display, and a setup hint that uses the consumer's command name.

dazzlecmd's `cli.py` is **unchanged** in this release. dazzlecmd's `_cmd_info` continues to use its own helpers. The collapse to a thin library wrapper ships in v0.7.33 (X-22-narrow). This commit is the prerequisite that ensures the collapse won't drop behavior.

## Prerequisites

1. dazzlecmd installed in editable mode (`pip install -e .` from project root)
2. dazzlecmd-lib editable install (auto-installed by dazzlecmd)
3. amdead installed in editable mode (`pip install -e C:\code\amdead`) for live consumer verification
4. Reset env vars before each section to avoid config bleed:
   - **cmd.exe**: `set DAZZLECMD_CONFIG=` (clears it)
   - **PowerShell**: `Remove-Item Env:\DAZZLECMD_CONFIG -ErrorAction SilentlyContinue`
   - **POSIX**: `unset DAZZLECMD_CONFIG`

## High-Value Verification (~5 minutes)

### HV.1 — `amdead info <tool>` shows full info display

Validates: library `render_info` produces dazzlecmd-equivalent output for library consumers.

- [ ] **Steps:** `amdead info detect`
- [ ] **Expected:** Standard info banner (Name, FQCN, Kit, Namespace, Version, Description, Platform, Runtime, Script, Shell). No shadow block (detect is not a reserved name).
- [ ] **Why this matters:** Baseline check that nothing broke for library consumers.

### HV.2 — `amdead info setup --raw` shows raw-runtime marker

Validates: `--raw` flag is now wired into library consumers' info subcommand.

- [ ] **Steps:** `amdead info setup --raw`
- [ ] **Expected:** Runtime line reads `Runtime:     shell  (raw, unresolved)`. Shadow block also present (setup is reserved + amdead overrides).
- [ ] **Why this matters:** Pre-port, amdead users had no way to see the raw manifest declaration. Post-port, `--raw` works for any library consumer.

### HV.3 — Setup hint uses consumer's command name

Validates: the setup hint now uses `engine.command` instead of literal `dz`.

- [ ] **Steps:** find a tool in amdead that declares `setup` block; run `amdead info <name>`
- [ ] **Expected:** if a setup hint appears, it reads `Run: amdead setup <fqcn>` (NOT `Run: dz setup ...`). If no tools declare `setup`, this step is N/A.
- [ ] **Why this matters:** Pre-port, the library hardcoded `dz` even for non-dazzlecmd consumers. Post-port, each aggregator sees its own command name.

### HV.4 — `dz info` is byte-equivalent to v0.7.31

Validates: dazzlecmd CLI is unchanged in this release.

- [ ] **Steps:** Run `dz info <each of 3 representative tools>` and compare output to v0.7.31 (mental diff or capture).
- [ ] **Expected:** Identical output (modulo any version-banner differences).
- [ ] **Why this matters:** Phase A (and this prerequisite) shouldn't touch dazzlecmd's CLI behavior.

### HV.5 — pytest baseline green

- [ ] **Steps:** `python -m pytest tests/ --ignore=projects/wtf -q`
- [ ] **Expected:** `975 passed, 13 skipped` (up from 967 in v0.7.31).

### HV.6 — Library `--platform` flag works in isolation

Validates: `--platform SPEC` invokes the platform preview path.

- [ ] **Steps:** `python -c "from dazzlecmd_lib.default_meta_commands import _print_runtime_platform_preview; _print_runtime_platform_preview({'runtime': {'type': 'python', 'platforms': {'linux': {'interpreter': '/usr/bin/python3'}, 'windows': {'interpreter': 'py.exe'}}}}, 'linux')"`
- [ ] **Expected:** Output: `Runtime:     python  (preview for linux)` followed by `Interpreter: /usr/bin/python3`.
