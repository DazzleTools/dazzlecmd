# Human Test Checklist -- `fixuser` (alias `fixusr`)

- **Tool:** `dz fixuser` / `dz fixusr` (canonical FQCN `dazzletools:fixuser`; grouped under virtual kit `dazzletools:windows:`)
- **Version target:** v0.10.2 (ships with `safe-icacls` + `redact-msinfo`; tool designed in the v0.7.55 batch)
- **What it does:** diagnoses and repairs a broken Windows user profile -- the
  temporary-profile / ProfileList `.bak` state plus stripped profile ACLs that
  result from running `takeown` / `icacls /reset` on a live profile.
- **Why a human checklist:** the automated tests mock the registry, `icacls`,
  admin and hive checks. They CANNOT cover: real SID resolution, a real
  `ProfileList` read, real ACL parsing of a real profile, the loop-safe grant
  over real profile junctions, real elevation/hive refusals, the actual backup
  files landing on disk, and console rendering. Those are exercised below.

> **RUN THESE IN POWERSHELL (elevated where noted) -- NOT Git Bash.** `fixuser`
> shells out to `icacls` / `reg` and reuses `safe-icacls`; MSYS/Git Bash rewrites
> `/`-style icacls args and breaks them (same caveat as `safe-icacls`).

---

## Prerequisites

- [ ] Windows 11, `dz` on PATH (`dz info dazzletools:fixuser` prints metadata).
- [ ] An elevated PowerShell for the repair/refusal sections; a normal
      (non-elevated) PowerShell available too (for the elevation-refusal test).
- [ ] A known-healthy local account to diagnose (e.g. `localuser`).
- [ ] (Part C only) A **throwaway** local test account you are willing to break
      and recreate. **Never run Part C against a real/important account.**

---

## Part A -- Diagnose (read-only, SAFE: changes nothing)

- [ ] **A1. Healthy profile.** `dz fixuser localuser`
      - Expect: `registry shape : HEALTHY`, `acl status : ok`,
        `VERDICT: healthy -- nothing to do.`
      - Expect exit code `0` (`$LASTEXITCODE`).
- [ ] **A2. Verbose raw values.** `dz fixuser localuser -vv`
      - Expect the named shape PLUS its explanation line, the raw ProfileList
        value line `[S-1-5-...-XXXX] path=... state=0`, and a per-node ACL list
        (root, NTUSER.DAT, UsrClass.dat) each `ok`.
- [ ] **A3. Debug verbosity.** `dz fixuser localuser -vvv`
      - Expect no error; same diagnosis (debug detail mainly appears during
        `--repair`, where each `icacls` invocation is echoed).
- [ ] **A4. Unresolvable account.** `dz fixuser definitely-no-such-user`
      - Expect: `could not resolve 'definitely-no-such-user' to a Windows
        account...`; exit code `2`.
- [ ] **A5. Help.** `dz fixuser -h` and `dz fixusr -h`
      - Expect the same help text from both (canonical + alias); the "THE BROKEN
        SHAPES" table is listed.

---

## Part B -- Repair refusals (SAFE: refuses, changes nothing)

- [ ] **B1. Refuses without elevation.** In a **non-elevated** PowerShell:
      `dz fixuser localuser --repair`
      - Expect: `error: --repair requires an elevated (admin) shell.`; exit `1`.
      - Confirm nothing changed: re-run `dz fixuser localuser` -> still HEALTHY.
- [ ] **B2. Refuses while the hive is loaded.** Open a session as the target
      (`runas /user:localuser cmd` -- this loads `HKEY_USERS\<SID>`), then in an
      **elevated** PowerShell: `dz fixuser localuser --repair --yes`
      - Expect: `error: ...'s hive is currently loaded ... will not repair a
        profile that is in use.`; exit `1`.
      - Close the `runas` shell afterward.

---

## Part C -- Real repair (DANGEROUS -- throwaway account ONLY)

> This deliberately breaks a profile to verify the repair. Do it on a disposable
> test account. Have the account's password handy. Reboot/relogon is required to
> fully verify.

1. [ ] Create + log in a throwaway account once so its profile exists
       (`C:\Users\<test>` with `NTUSER.DAT`). Log it OFF.
2. [ ] **Break it** (reproduce the real-world cause) from elevated PowerShell:
       `takeown /F "C:\Users\<test>" /A /R /D Y /SKIPSL` then
       `icacls "C:\Users\<test>" /reset /T /C` (this strips the private ACL).
       (Or just remove the user's explicit ACE from `UsrClass.dat`.)
3. [ ] Log the test account ON, then OFF. Confirm it temp-profiled:
       Event Viewer -> Application -> "User Profile Service" Event 1511/1515, and
       a `<SID>.bak` (or `\Users\TEMP` active) key in
       `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList`.
4. [ ] **Diagnose:** `dz fixuser <test> -vv` -> expect a non-HEALTHY shape named
       (BAK-ONLY / TEMP-ACTIVE + BAK / etc.) and `acl status : BROKEN`, exit `2`.
5. [ ] **Repair (test account signed OUT):** `dz fixuser <test> --repair`
       - Confirm the prompt; or use `--yes`.
       - Expect a `backup:` line printing `~/.fixuser/backups/<SID>_<timestamp>/`
         and a `revert ACL grant if needed:` hint.
       - Expect each action echoed (`-> grant ...`, `-> promote ...`, `-> set
         State=0`) and `repair complete.`; exit `0`.
6. [ ] **Verify backups on disk:** the printed
       `~/.fixuser/backups/<SID>_<timestamp>/` contains:
       - `ProfileList.reg` (non-empty; openable, has the SID key)
       - `acls-before.txt` (pre-change `icacls` of root + NTUSER.DAT + UsrClass.dat)
7. [ ] **Verify the fix:** `dz fixuser <test>` -> HEALTHY, exit `0`. Log the test
       account ON; in its shell `echo %USERPROFILE%` -> `C:\Users\<test>` (NOT
       `C:\Users\TEMP`).
8. [ ] **(Optional) --harden:** re-run with `--repair --harden` and confirm the
       profile root becomes inheritance-protected and `Everyone`/`Users` are gone
       (`icacls "C:\Users\<test>"`).

---

## What the automated tests DON'T cover (covered here)

- Real `LookupAccountName`/SID resolution and a real `ProfileList` read.
- Real `icacls` ACL parsing of a real profile (the `acl_user_has_full` heuristic).
- The loop-safe grant walking a REAL profile's self-referential junctions
  (mocked tests assert ops, not real traversal).
- Real elevation (`IsUserAnAdmin`) and real hive-loaded (`HKEY_USERS\<SID>`) checks.
- Backup files actually being written to `~/.fixuser/backups/...`.
- Console rendering / verbosity in a real terminal codepage.
- The PowerShell-vs-Git-Bash `/`-arg caveat.

## Cleanup

- [ ] Close any `runas` shells opened in Part B.
- [ ] (Part C) Remove the throwaway account + its profile if no longer needed.
- [ ] Backups under `~/.fixuser/backups/` are safe to keep or `dz safedel`.
