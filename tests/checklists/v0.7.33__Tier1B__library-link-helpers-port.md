# Human Test Checklist: v0.7.33 — Tier 1B — Library link-helpers port (final library prerequisite)

**Target version:** v0.7.33 **Ships with commit:** TBD (final library prerequisite before v0.7.34 X-22-narrow CLI collapse) **Companion automated tests:** 984 passing in `tests/` (9 new tests across `tests/test_paths.py` + `tests/test_default_meta_commands.py::TestRenderInfo`)

## What this is

v0.7.33 ports `is_linked_project()` and `get_link_target()` from `dazzlecmd.importer` to `dazzlecmd_lib.paths`. Library `render_info` now shows a "Linked to: <target>" line when a project is a symlink or Windows junction. The dazzlecmd-side import surface stays stable via a back-compat re-export, so `mode.py`, tests, and any external caller continue to work unchanged.

This is the third and final library-parity port preparing for the v0.7.34 X-22-narrow CLI collapse. After v0.7.33, every dazzlecmd-CLI behavior in `_cmd_list`/`_cmd_info`/`_cmd_tree` has a library equivalent; the v0.7.34 collapse can proceed without behavior loss.

dazzlecmd's `cli.py` is **unchanged** in this release. dazzlecmd's `_cmd_info` continues to print "Linked to:" via its existing local code (which now resolves through the back-compat re-export to the library helpers).

### 1.3 `get_link_target` for normal directory

- [ ] **Steps:** `python -c "from dazzlecmd_lib.paths import get_link_target; import tempfile, os; d = tempfile.mkdtemp(); print(get_link_target(d)); os.rmdir(d)"`
- [ ] **Expected:** `None`.

### 1.4 Symlink detection (POSIX or Windows with Developer Mode)

- [ ] **Steps (POSIX or Windows-Dev-Mode)**:
  ```bash
  python -c "
  from dazzlecmd_lib.paths import is_linked_project, get_link_target
  import tempfile, os
  src = tempfile.mkdtemp()
  link = src + '_link'
  os.symlink(src, link, target_is_directory=True)
  print('is_linked:', is_linked_project(link))
  print('target:', get_link_target(link))
  os.unlink(link)
  os.rmdir(src)
  "
  ```
- [ ] **Expected:** `is_linked: True`, `target: <path>`.
- [ ] **Skip if:** symlink creation isn't permitted on this platform.

## Section 4: Cross-shell verification

### 4.1 `is_linked_project` ctypes path on Windows

- [ ] **Steps (PowerShell):** `python -c "from dazzlecmd_lib.paths import is_linked_project; import sys; print(sys.platform); print(is_linked_project('C:/Windows'))"`
- [ ] **Expected:** `win32`, `False`. Confirms the ctypes-based detection path runs without error on Windows.

### 4.2 Junction detection (Windows-only)

- [ ] **Steps (PowerShell, requires admin or Developer Mode for symlink, but `mklink /J` works without):**
  ```powershell
  $src = New-TemporaryFile | %{ Remove-Item $_; New-Item -ItemType Directory -Path $_.FullName }
  $link = "$($src.FullName)_link"
  cmd /c "mklink /J `"$link`" `"$($src.FullName)`""
  python -c "from dazzlecmd_lib.paths import is_linked_project; print(is_linked_project(r'$link'))"
  cmd /c "rmdir `"$link`""
  Remove-Item $src.FullName
  ```
- [ ] **Expected:** `True`. Confirms junction detection works.
