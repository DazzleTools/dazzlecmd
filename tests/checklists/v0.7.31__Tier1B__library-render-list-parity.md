# Human Test Checklist: v0.7.31 — Tier 1B (Phase A) — Library `render_list` parity + public `build_list_entries` API

**Target version:** v0.7.31 **Ships with commit:** TBD (Phase A of the 4b-T9 / X-22-narrow two-commit sequence) **Companion automated tests:** 967 passing in `tests/` (20 new tests across `tests/test_default_meta_commands.py::TestRenderList`, `TestBuildListEntries`, `TestRenderTree`)

## What this is

v0.7.31 is a library-only release. `dazzlecmd-lib` reaches parity with dazzlecmd's CLI for the `list` and `tree` rendering surfaces, exposes `build_list_entries` as a public stable API, and makes virtual kits visible in `tree` output. **dazzlecmd's `cli.py` is unchanged** in this release — the duplication collapse ships in v0.7.32 (Phase B).

This checklist focuses on the LIBRARY consumer experience (amdead, wtf-windows, future personal aggregators). dazzlecmd's `dz` invocations should be byte-equivalent to v0.7.30 since dazzlecmd's CLI didn't change.

## Section 3: New library API surface verification

### 3.1 Direct import of `build_list_entries`

- [ ] **Steps:** Open a Python interpreter:
  ```python
  from dazzlecmd_lib.default_meta_commands import build_list_entries
  result = build_list_entries(
      [{'name': 'alpha', '_fqcn': 'core:alpha', '_kit_import_name': 'core', 'description': 'test'}],
      None,
      'canonical',
      None
  )
  print(result)
  ```
- [ ] **Expected:** A list with one entry dict. `result[0]['entry_type']` == `'canonical'`. `result[0]['_fqcn']` == `'core:alpha'`. `result[0]['has_aliases']` == `False`.

### 3.2 Direct import of `render_list` with backward-compat path

- [ ] **Steps:**
  ```python
  from dazzlecmd_lib.default_meta_commands import render_list
  from types import SimpleNamespace
  args = SimpleNamespace(namespace=None, kit=None, tag=None, platform=None, show=None)
  rc = render_list(args, [{'name': 'alpha', '_kit_import_name': 'core', 'description': 'test', 'platform': 'cross-platform'}])
  ```
- [ ] **Expected:** `rc == 0`. Output is the legacy flat table (Name | Kit | Description format, "1 tool(s) found" footer). No errors about missing `engine` parameter.

### 3.3 `--show` flag is in argparse subparser

- [ ] **Steps:** Build a test aggregator with `register_all()`. Verify `aggregator list --show all` parses without error.
- [ ] **Expected:** `args.show == 'all'` after parsing. Choices restricted to `default|canonical|alias|all`.

### 3.4 `_wrap_description` helper accessible

- [ ] **Steps:**
  ```python
  from dazzlecmd_lib.default_meta_commands import _wrap_description
  print(_wrap_description("This is a long description that needs wrapping at the right spot.", 30))
  ```
- [ ] **Expected:** A list of strings, each ≤30 chars (wrapped at word boundaries).
