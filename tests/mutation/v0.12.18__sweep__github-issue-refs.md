## Headline

The suite entered the audit at 63 tests, all green, written the same day as the code
against explicit acceptance checks -- and **9 of 22 generated mutants survived it**
(41%). Every survivor was triaged; 8 were killable and now have anchors demonstrated
red-under-mutant and green-on-real; 1 is a recorded don't-care. Final state: **70
tests, 21/22 mutants killed, 1 triaged don't-care survivor.**

The instructive pair: M1 (round 1) broke case-folding on the *cache* side and R1
(round 2) broke it on the *query* side. The anchor written for M1 does not kill R1 --
each direction of a fold needs its own anchor, and a hand-written "red check" for M1
would likely have used an uppercase query and killed neither.
